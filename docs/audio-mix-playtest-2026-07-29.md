# 전투 오디오 믹스 플레이테스트 — 2026-07-29

## 수정 전 문제

- 배경음, 전투 효과음, UI 효과음이 모두 출력 장치에 직접 연결되어 음량 우선순위와 여유 폭이 없었다.
- 다수 유닛이 동시에 공격하면 같은 종류의 발사·피격·폭발음이 매번 재생되어 소리가 겹쳤다.
- 짧은 톱니파 음이 반복되는 기존 배경음은 고딕 전장의 분위기와 맞지 않았고, 중요한 폭발도 일반 공격음 사이에 묻혔다.

## 적용 내용

- `Music`, `SFX`, `UI` 버스를 분리하고 `Master` 버스에 리미터를 배치했다.
- 기준 음량은 Master -4 dB, Music -15 dB, SFX -2 dB, UI -6 dB로 설정했다.
- 발사 55 ms, 피격 45 ms, 일반 폭발 120 ms, 마법 90 ms, UI 클릭 25 ms 이내의 중복 보이스를 억제한다.
- 보스 사망, 기지 파괴, 천벌, 악마 저주는 제한을 우회하는 중요 폭발로 분류하고 배경음을 순간적으로 낮춘다.
- 배경음을 저역 삼각파 기반의 느린 고딕 펄스로 바꾸고, 실제 교전 강도에 따라 상부 음층과 음악 음량이 완만하게 증가하도록 했다.
- 개발자 정보에 재생·억제 보이스 수, 교전 강도, 세션 최고 피크, 오디오 출력 상태를 표시한다.

## 실제 브라우저 플레이 결과

조건: NORMAL, 수도승 8 + 엑소시스트 8, 3배속, 웨이브 조기 개시.

- 첫 대규모 교전: 34개 보이스 재생, 11개 중복 보이스 억제, 세션 최고 피크 7%.
- 천벌을 포함한 후속 교전: 118개 보이스 재생, 96개 중복 보이스 억제, 세션 최고 피크 10%.
- 오디오 컨텍스트가 `running` 상태였고 디버그 표시는 `출력 정상`으로 유지됐다.
- 사운드 끄기 → 켜기 왕복 조작 후 두 UI 버튼의 상태가 함께 복원됐다.

브라우저 계측으로 출력 상태, 중복 억제, 피크 여유 폭, 조작 동작을 확인했다. 실제 스피커·헤드폰의 주관적 음색과 최종 체감 음량은 사용자 청취 환경에서 한 차례 더 확인할 필요가 있다.

# EXORCISM: 신성한 전쟁

성직자 교단과 악마 군단이 맞붙는 PC 웹 전략 디펜스 게임입니다. 유닛 생산, 경제 투자, 성서 계시(테크), 전장 전체를 타격하는 천벌을 조합해 지옥문을 파괴하세요.

## 🎮 지금 바로 플레이하세요!
**웹 브라우저에서 바로 플레이:** [https://jwh1124.github.io/DS/](https://jwh1124.github.io/DS/)

## 플레이 안내

- 지원 환경: 키보드와 마우스를 사용하는 PC 또는 900×600px 이상 가로 화면
- [1]~[6]: 유닛 소환 / Shift+[1]~[6]: 해당 유닛 환속
- [Q]: 헌금 투자 / [W]: 성서 계시 / [E]: 천벌 / [Esc]: 일시정지
- 카메라는 전선을 자동 추적하며, [A/D]로 수동 이동하거나 [Space]로 자동 추적을 켜고 끌 수 있습니다.
- 첫 웨이브까지 15초 동안 초기 조합을 준비합니다.

## 주요 특징

- 유닛과 테크 레벨을 통한 조합형 전투
- 공정한 테크 해금 규칙: AI와 플레이어 모두 같은 병종 해금·테크 비용 규칙을 사용
- 고딕 성당과 지옥문, 전용 유닛 일러스트, 전투 이펙트·사운드
- 미니맵, 툴팁, 우클릭 환속, 일시정지 지원

## 🛠️ 로컬 개발 환경 구축
직접 프로젝트를 로컬에서 실행해 보고 싶다면:
1. 리포지토리 클론 (Clone)
2. `npm ci` 실행
3. `npm run dev` 실행
4. 브라우저에서 `http://localhost:5173/` 접속

## 검증

```bash
npm test
npm run build
```

`?dev=1`을 URL 뒤에 붙이면 QA를 위한 속도·자원·자동 소환 도구와 상세 전투 정보를 표시합니다. 일반 플레이 화면에는 노출되지 않습니다.
